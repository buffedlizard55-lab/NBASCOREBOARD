Where every number comes from

The site reads published copies of NBA-owned feeds, not ESPN or other aggregators. An automated GitHub Actions job fetches NBA.com / cdn.nba.com; the browser reads the copies here. This is a snapshot, not a guaranteed live connection. Click a game's NBA link to review the original.

Date-page evidence · Browser access evidence · Verification notes

Coverage and reliability limitations
  • GitHub Actions schedules may be delayed or skipped. Refreshing this page cannot make a stale publication newer. The capture/check time and any ingestion failures are shown above; NBA.com is the live reference.
  • Full game detail is attempted while games are in progress and at final for the NBA CDN era (sampled from 2019–20). Older seasons have date-level scores when archived, but no confirmed CDN play-by-play here. Some older regular-season detail is pruned to fit the repository.
  • Only captured dates and the currently published NBA season schedule can be browsed here; we do not label an unarchived date or a failed fetch as “no games.” We do not publish unverified standings.
